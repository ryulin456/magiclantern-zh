这不是“实机验证通过”的正式版。本包已通过电脑端构建、校验、翻译、布局和模块符号审计，但仍必须在 Canon 70D、原厂固件 1.1.2 上完成实机测试。

r3 修复了什么
=============

旧汉化实现把 134502 字节中文字体和约 78 KB 语言表放在临时/DMA 内存中，并在开机后长期保留。Magic Lantern 的内存代码明确说明，这类临时拍摄内存在进入佳能菜单时应保持空闲。r3 改为：使用最多 32 KB 的短时 DMA 缓冲区分块读取，复制到持久、非 DMA 内存，然后在函数返回前立即释放临时缓冲区。

这项修复与“装卡黑屏、红灯持续、佳能菜单异常”的现象相符，但没有 70D 实机数据时不能宣称问题已经彻底解决。

首次安装／测试必须使用干净卡
===========================

1. 先备份卡上的照片和旧 ML 目录。
2. 不要把本包直接覆盖到旧 ML 目录。请在相机中格式化测试卡，或先在电脑上移走整个旧 ML 目录。
3. 将本 ZIP 的全部内容解压到卡根目录，保持 autoexec.bin、ML 文件夹和 ML-SETUP.FIR 的目录结构不变。
4. 确认相机是 70D、原厂固件正好为 1.1.2，再按照 Magic Lantern 官方 70D 1.1.2 安装步骤运行固件更新。
5. 本包不含任何模块启用文件（ML/SETTINGS/*.en）。首次启动不要恢复旧设置，也不要启用任何模块。

首次实机验收
============

1. 先确认相机不插卡时能够正常开机。
2. 建议先用另一张干净卡测试原英文 magiclantern.2025-06-20.70D.112.zip，确认同一台相机和同一张卡的基础环境正常。
3. 插入本包测试卡，将模式转盘置于 M，开机并等待至少 30 秒。
4. 检查佳能菜单、实时取景、回放、Magic Lantern 菜单以及正常关机。
5. 不启用模块，完成至少 10 次“关机－取电池－重新装电池－冷启动”。
6. 基线全部通过后，才可一次启用一个模块；每启用一个都要重启、打开菜单、做最小功能测试、正常关机并再次启动。

70D 源码定义了 CONFIG_NO_ADDITIONAL_VERSION，因此 Magic Lantern 不会在佳能固件版本文字后追加自身版本。请在 M/P/Tv/Av 模式检查佳能菜单中的原厂固件版本项；看不到追加的 Magic Lantern 字样是正常的，但整个原厂固件版本菜单项异常消失并不正常。

发生黑屏／红灯持续时
====================

1. 关闭电源，取出电池和存储卡；等待片刻后只装电池、无卡开机。
2. 如果无卡可开机，说明原厂固件大概率仍在，停止使用该卡并保留卡内日志；不要继续反复启动。
3. 可在装卡启动时一直按住 SET，尝试临时禁止 Magic Lantern 启动。
4. 如果无卡仍无法开机，不要盲目重复刷写固件；记录相机固件、卡片、包 SHA-256、LED 状态和操作步骤，再寻求 Magic Lantern 官方论坛或相机维修支持。

模块与汉化范围
==============

本包保留平台清单中的全部 19 个模块，包括隐藏／实验模块；没有为了通过构建而删除模块。电脑端审计结果：核心菜单 804/804，模块固定界面 525/525，动态格式 51/51，格式占位符 123/123；19 个模块全部可解析其依赖符号。模块可链接不等于实机功能已经验证。
