# 6D2 1.1.1 简体中文 r3 完整静态发布审计报告

## 发布结论

本构建通过 L1 静态发布门禁，状态为 `TEST-ONLY`。r3 修复了 r2 中中文 BFNT 从 32 像素缩小到 23 像素时可能跳过整条细横画的问题，并新增模块摘要、详情页布局和字形笔画分量门禁。

静态检查不能代替 6D2 实机显示、启动和模块操作测试；在完成 L2 测试矩阵前，不得标记为稳定版或公开正式版。

## 本次发现和修复

r2 的字库包含“一”等字符，因此原来的“缺字检查”会通过；但旧渲染器在 32→23 像素缩小时只取单个源像素行，恰好会跳过“一”所在的横行，使整字在模块摘要和详情中消失。全量发布文字中，旧路径还会让 15 个字符的至少一个独立笔画分量被跳过。

r3 对备用 CJK 单色 BFNT 的缩小路径改用不重叠覆盖采样：每个源像素只归入一个目标像素区域，只要区域中存在笔画就保留该目标像素。佳能原字体、图标和放大路径保持原逻辑，避免改变其他显示行为。

## 实机必测项目

1. 冷启动 10 次，检查黑屏、红灯异常、卡启动和拔卡恢复。
2. 逐个选择 19 个模块，拍摄底部一行摘要，确认无截断和换行。
3. 逐个打开模块详情页，确认正文最后一行完整且不覆盖页脚。
4. 重点检查含“一、与、交、修、查”的菜单和说明，确认没有缺横画、笔画粘连或模糊。
5. 逐个加载包内 3 个 `.mo`，检查菜单可打开、子选项可操作、关机重启正常。

出现一次启动黑屏、红灯异常、模块无法打开、整字消失或明显缺笔画，立即停止分发并退回 L1 分析。
