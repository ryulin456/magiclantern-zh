# 70D 1.1.2 汉化 r3 内存安全修复审计

结论：电脑端检查全部通过；状态仅为 **REALCAM-TEST**，尚未取得 Canon 70D 1.1.2 实机启动证据，不能标记为正式可用或“测试无误”。

## 故障定位与修复

旧实现使用 `read_entire_file()` 常驻读取 `zh_cn.bfn` 和 `zh_cn.lng`。该函数通过 `fio_malloc()` 请求 `MEM_TEMPORARY | MEM_DMA`，可能选择 `shoot_malloc`；`src/mem.c` 对该分配器的注释明确要求，在导航佳能菜单时应保持完全空闲。旧实现却把中文字体和语言表保留至整个运行期。

r3 新增 `read_entire_file_persistent()`：

- 最终缓冲区使用非 DMA、非临时的 `malloc()`；
- 文件通过最多 32 KiB 的短时 DMA 缓冲区分块读取；
- 成功和全部错误路径都会关闭文件、释放临时缓冲区；
- `menu.c` 的语言表和 `rbf_font.c` 的备用中文字体均改用新函数。

这是一个确定存在的内存生命周期错误，也是目前最符合“佳能菜单异常、黑屏、红灯”的代码原因；但“它就是该用户相机黑屏的唯一原因”仍需实机 A/B 测试确认。旧卡残留 `ML/SETTINGS/*.en` 自动加载模块仍是独立风险，因此本包强制要求干净卡测试。
