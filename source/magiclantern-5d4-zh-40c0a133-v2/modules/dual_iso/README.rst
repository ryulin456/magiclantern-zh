Dual ISO
========

:Author: a1ex
:License: GPL
:Summary: 5D4 1.3.3 暂不可用的双 ISO 占位模块
:Forum: http://www.magiclantern.fm/forum/index.php?topic=7139.0

上游构建清单保留此模块并将它标记为隐藏，但当前源码没有 5D4 的
CMOS ISO 地址。本包只编入不可用提示说明，加载时返回不支持。
没有传感器写入代码、拍摄回调或双 ISO 功能菜单。

保留此文件只是为了与上游 5D4 模块清单一致，不代表 5D4 已支持双 ISO。
不得复制 5D3 或其他机型地址来强行启用。
